# 🎬 Movie Database
Movie Database — это учебный JavaScript-проект, демонстрирующий работу с DOM, событиями, асинхронными запросами, таймером, табами и модальными окнами. В проект встроен сервер с JSON-данными, реализована сборка с помощью Gulp и деплой на GitHub Pages.

[👉 Демо на GitHub Pages] (https://mvamks.github.io/Movie_Database)

## 🧩 Основной функционал
    * ✅ Удаление рекламных блоков со страницы
    * ✅ Замена жанра фильма и фона постера через JavaScript
    * ✅ Динамическое добавление фильмов пользователем
    * ✅ Автоматическая сортировка фильмов по алфавиту с нумерацией
    * ✅ Удаление фильмов из списка
    * ✅ Вкладки (табы)
    * ✅ Таймер до конца акции
    * ✅ Модальное окно с отложенным и автоскролл-триггером
    * ✅ Отправка формы с уведомлением
    * ✅ Сборка через Gulp + Webpack + Babel
    * ✅ Продакшн-сборка с минификацией
    * ✅ Деплой на GitHub Pages

## 🚀 Быстрый старт
```bash
git clone https://github.com/mvamks/Movie_Database.git
cd Movie_Database
npm install
npm start
```
Запуск локального сервера: (http://localhost:4000)

## ⚙️ Скрипты
| Команда	            |Назначение                             |
|-----------------------|---------------------------------------|
|`npm start`            |Запускает Gulp + browserSync (dev-режим)|
|`npm run build`        |Собирает проект (dev-сборка)           |
|`npm run prod`	        |Продакшн-сборка с минификацией CSS/JS  |
|`npm run deploy`       |Публикация проекта на GitHub Pages     |

## 🛠️ Используемые технологии
* **JavaScript ES6+**
* **HTML5 / SCSS (Sass)**
* **Gulp** — автоматизация задач
* **Webpack** — сборка JS
* **Babel** — транспиляция в ES5
* **BrowserSync** — hot-reload
* **GitHub Pages** — деплой
* **Fetch API** — отправка форм
* **JSON Server** (опционально для тестов)


## 🖼️ Примеры UI

* Модальное окно (по клику, по таймеру, при скролле)
* Динамический список фильмов с удалением
